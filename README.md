# ❌⭕ Tic-Tac-Toe – Classic 3x3 Game

**Play the classic Tic-Tac-Toe with your friend directly in the browser.**

A simple and fun Tic-Tac-Toe game where two players take turns placing either "X" or "O" on a 3x3 grid. The first player to line up three matching symbols horizontally, vertically, or diagonally wins the game.

## ✨ Features

- Two-player mode (no AI)
- Real-time score tracking
- Draw detection (in case of a tie)
- Reset button for restarting the game

## 🛠️ Built With

- HTML
- CSS
- JavaScript

## 📁 How to Play

1. Clone or download the repository.
2. Open `index.html` in your browser.
3. Click on an empty cell in the 3x3 grid to make your move.
4. The first player to get three of their symbols in a row wins.
5. Use the restart button to start a new game.
