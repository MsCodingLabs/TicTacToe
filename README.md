# ❌⭕ Tic-Tac-Toe – Classic 3x3 Game

Relive the classic Tic-Tac-Toe experience with a friend directly in your browser!  
In this simple, two-player game, take turns placing "X" and "O" on a 3x3 grid. The first to get three in a row – horizontally, vertically, or diagonally – wins. Easy to play, but always exciting!
